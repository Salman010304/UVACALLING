આ ડિવાઇસના જૂના ડેટા ક્લાઉડમાં અપલોડ કરો
જો તમે પહેલા એક્સેલ ઈમ્પોર્ટ કરી હોય અને બીજા મોબાઈલ/PC માં ન દેખાતી હોય તો અહીં ક્લિક કરો:
જો Firebase માં "Permission Denied" એરર આવે તો શું કરવું?

૧. Firebase Console (console.firebase.google.com) ખોલો ➔ તમારા પ્રોજેક્ટ uvacalling માં જાઓ.
૨. ડાબી બાજુ Firestore Database ➔ ઉપર Rules ટેબ પર ક્લિક કરો.
૩. નીચે મુજબના Rules પેસ્ટ કરીને Publish દબાવો જેથી બધા ડિવાઇસમાં ડેટા સેવ થાય: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
